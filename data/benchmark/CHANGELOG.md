# Benchmark changelog

Each version transition uses the same table format. Question IDs refer to the destination version. `text` denotes the question wording and its corresponding key in `answers.json`. Changes to `kind` apply in both source files. Page indices in the v1 results are zero-based physical PDF indices. Separate bracketed lists denote separate evidence pools.
